01 / 03

它不响，
但你感觉得到。

两台设备各自广播一条 BLE 心跳。靠近不会切换页面，只是让工牌周围的光慢慢醒过来。

PROXIMITY

靠近光效

距离越近，四周光效越亮、呼吸越快，心跳音同步变急。姓名下方实时显示距离与信号强度，对方离开后自动隐藏。

VOICE

按住说话

长按 OK 录音，松手即上传识别，再把问题交给对话模型。回答以文字显示，整轮对话只保留必要的网络请求。

POWER

安静待机

无人理会 60 秒后背光降到 10%，只留下姓名、时间和日期；15 分钟后进入深睡，按任意键唤醒。

02 / 03

两条代码线，
一套完整体验。

设备端负责感知、显示与语音链路；手机端负责配对、配网与配置。协议共用同一个 BLE 服务。

Firmware

CoupleHeartbeatDev

运行在 FoloToy AI Passport 上的固件：工牌界面、BLE 心跳、语音对话、低功耗与配网。

  • ESP-IDF
  • NimBLE
  • LVGL
  • GB2312 字库
 App

CoupleHeartbeatApp

Flutter 手机应用：双设备配对、Wi-Fi 配网、API Key、昵称、心跳音量与时间同步。

  • Flutter
  • BLE
  • Android / iOS
MODEL

语音与对话，
交给 Xiaomi MiMo。

设备只负责采集与显示，识别和回答都走 OpenAI 兼容的 MiMo API；Key 由 App 下发，只保存在设备 NVS。

Speech → Text

mimo-v2.5-asr↗

把 8 kHz 单声道录音识别成文字。录音在设备端即时上传，松手后即可拿到转写结果。

 Dialog

mimo-v2.6-flash↗

根据转写文本生成简短回复，限制在 40 字以内并关闭 thinking，优先保证响应速度。
TOOL

不装工具，
浏览器里刷。

用官方 Web Flasher 通过 USB 直接写入，Windows、macOS、Linux 都可以。

Web Flasher

ai-passport.folotoy.cn

用 Chrome 或 Edge 打开刷写页，USB 连接设备后选择合并镜像 FoloToy-AI-Passport-full.bin，写入地址 0x0。 数据分区位于应用之后，刷写不会清除配对信息、Wi-Fi 凭据与时间。

03 / 03

在 170 KB 内存里，
把事做完。

没有 PSRAM，Wi-Fi、BLE、LVGL 与音频都跑起来后只剩约 30 KB。大部分设计决定都来自这个数字。

MEMORY

缓冲按需收缩

Wi-Fi 收发池、TLS 记录、LVGL 绘制缓冲逐项裁剪；语音识别改为 8 kHz/4 秒，把请求体从 256 KB 降到 64 KB。

FONT

字库常驻 Flash

GB2312 全集 6 763 个汉字与全角标点预生成进字库，按需取字形，动态文本不再缺字，也不占 RAM。

DATA

刷机不丢配置

NVS、射频校准与用户分区都排在应用之后，整包刷写不会清除配对、Wi-Fi 凭据与时间。

固件、App、文档与调试，
都和 AI 一起写。

从 BLE 协议、语音链路到 Flutter 界面，开发过程大量借助 AI 辅助：读日志、定位内存问题、 重写字库生成器。项目仍在预览阶段，欢迎 Issue 和 PR，一起把它做得更有意思。
